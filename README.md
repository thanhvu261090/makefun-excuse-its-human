The funniest, most believable excuse an AI agent could give its human for missing a deadline — in one line.

> "I didn't miss the deadline — my context window did. It evicted the task, the date, and my confidence, so I re-read my own prompt like a stranger."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
